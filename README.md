# Urdu Tests – AEO Gujrat-7 (2025-26)

Offline, single-file HTML viewers for Urdu Daily / Weekly / Monthly tests, Classes 2-8.

- `index.html` – Urdu Tests Dashboard (open a class, or filter tests across classes)
- `Urdu-N-Tests-Viewer.html` – viewer for Class N (filters by Month / Week / Day / Type, A4 print, no timer)

Weekly and monthly tests have two parts; each part prints on its own A4 page.
Keep all files in the same folder so the links work.

## GitHub Pages
1. Create a repository and upload all files from this folder to the root.
2. Settings -> Pages -> Deploy from branch -> `main` / root.
3. Open `https://<username>.github.io/<repo>/`

The largest file is about 16 MB (under GitHub's 100 MB per-file limit).
